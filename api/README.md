# API

This folder will contain the Python Azure Functions backend for the AI-Powered Customer Sentiment Dashboard.

Planned work for this folder:

- Sentiment integration with Azure AI Language’s prebuilt sentiment analysis
- CSV processing for uploaded review files (required column: `review_text`)
- Database access for storing and reading reviews and analysis results in Azure Cosmos DB
- Dashboard statistics that support history, charts, trends, and filters
- Alert evaluation that decides when negative feedback should trigger an Azure Logic Apps email
